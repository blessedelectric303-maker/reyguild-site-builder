## Two notes before you hand this to anyone

**The safety document is electrical.** It cites NFPA 70E, Class 00 and Class 0
rubber insulating gloves and the six month test interval. A plumber or an HVAC
company cannot use it as written - they need their own, for their trade.

**None of this is legal advice.** It is a solid working draft written to match
what the app does. Have a Colorado attorney read the booklet, both NDAs and the
platform terms before the first paying customer signs.
